# 세탁기 실시간 동작 현황 및 관제 웹 시스템
- 제품명: WashOn

## 1. why - 목적
### 배경 및 문제 정의
외부 관리 장비의 한계:
현재 세탁기는 타사(코인업 등)에서 관리하고 있어 장비 내부 배선 개조, 전원선 분리, 내부 통신선 커넥터 부착 등의 침습적 방식이 불가능합니다.

이용자 불편 (End User):
세탁기/건조기의 현재 잔여 시간 및 사용 가능 여부를 매장 방문 전에는 알 수 없어 불필요한 대기 시간 발생.

관리자 불편 (Admin):
세탁기 디스플레이에 표시되는 에러 코드(예: E01 급수 오류, E04 배수 오류 등)가 발생해도 현장에 상주하지 않아 즉각적인 장애 대응이 불가능.

### 해결 방안: AI 비전(카메라) 기반 OCR 인식
세탁기 전면 디스플레이 및 LED 상태등을 비추는 카메라 모듈을 설치하고, AI OCR 엔진이 인식한 디스플레이 텍스트/상태 데이터를 REST API/MQTT로 웹 백엔드에 전송합니다.
웹 프로젝트는 수신된 OCR 데이터를 가공·보정하여 사용자에게 직관적인 실시간 상태 및 잔여 시간 UI를 제공하고, 관리자에게 실시간 장애 관제 및 알림을 제공합니다.

## 2. Who - 타켓 사용자
### 세탁 서비스 이용자
매장 방문 전 세탁기/건조기 실시간 가동 현황 및 잔여 시간 확인.
앱 설치 없이 QR 코드만으로 빠른 현황 조회.
세탁 종료 시점에 맞춘 정밀한 완료 알림(카카오 알림톡) 수신.

### 매장/시설 관리자
원격으로 매장 내 전체 세탁기의 실시간 동작 및 디스플레이 상태 파악.
세탁기 디스플레이의 에러 코드(E01, E04 등) 및 이상 동작 즉시 감지 및 알림 수신.
오인식 발생 시 카메라 실시간 캡처 이미지 확인을 통한 원격 점검.

## 3. User flow
### 학생: 방문 전 확인 
학생이 기숙사 공지, 세탁실 QR 코드, 또는 즐겨찾기로 웹 페이지에 접속한다. 로그인 없이 바로 볼 수 있다.
첫 화면에 자주 보는 세탁실(마지막으로 본 세탁실)이 표시된다. 다른 세탁실은 동과 층을 골라 이동한다.
세탁실 요약을 본다. 예: 세탁기 3대 중 1대 사용 가능, 건조기 2대 중 0대 사용 가능.
기기별 상태를 확인한다. 상태는 사용 가능, 사용 중(남은 시간), 종료 후 세탁물 방치, 확인 불가 중 하나다.
사용 가능한 기기가 있으면 세탁실로 간다.
없으면 가장 빨리 끝나는 기기의 예상 시간을 보고 그 시점에 다시 확인하거나 방문한다.
(P1) 빈 기기 알림을 신청해 두면 기기가 비었을 때 웹 푸시로 알림을 받는다.

### 학생: 상태 오류 제보
화면 상태와 실제 상태가 다르면 해당 기기의 "상태가 달라요" 버튼을 누른다.
실제 상태를 고른다. 예: 비어 있음, 사용 중, 고장.
제보가 관리자 화면에 쌓이고, 같은 내용의 제보가 여러 건이면 해당 기기에 "확인 필요" 표시가 붙는다.
제보 데이터는 AI 인식 모델 개선에 쓰인다.

### 관리자: 모니터링과 보정
관리자 계정으로 로그인한다.
전체 세탁실의 기기 상태와 카메라 연결 상태를 한 화면에서 본다.
카메라 연결 끊김, 인식 신뢰도 저하, 학생 제보가 발생하면 알림을 받는다.
필요하면 기기 상태를 수동으로 지정한다. 예: 고장으로 지정하면 학생 화면에 즉시 반영되고 자동 판별보다 우선한다.
조치 후 수동 지정을 해제하면 자동 판별로 돌아간다.

## 4. 기능 요구 사항 및 우선순위
### 우선순위 정의 (Priority Class)
- P0 (Critical): 필수 구현 기능 (미구현 시 서비스 불가능)
- P1 (High): 서비스 완성도 및 안정성을 향상시키는 주요 기능
- P2 (Medium/Low): 고도화 단계에서 추가할 선택 기능

### 4.1. 이용자 기능 (User Features)
- 실시간 장비 상태 조회
우선순위: P0
설명: 세탁기별 현재 상태(대기 중, 사용 중, 완료, 점검 중)를 모바일 화면에 실시간으로 표시합니다.

- QR 코드 간편 진입
우선순위: P0
설명: 세탁기에 부착된 QR 코드를 모바일 카메라로 스캔하면 별도 앱 설치 없이 해당 장비 모바일 웹 페이지로 직접 이동합니다.

- 세탁 완료 알림
우선순위: P0
설명: 세탁 완료 5분 전 및 세탁 종료 시점에 카카오 알림톡으로 알림 메시지를 발송합니다.

- 잔여 시간 및 진행 단계 조회
우선순위: P1
설명: AI 비전 OCR이 인식한 잔여 시간(분 단위)과 세탁 단계(세탁, 행굼, 탈수)를 시각적 아이콘 및 타이머로 제공합니다.

- 주변 매장 및 세탁실 검색
우선순위: P1
설명: 위치 기반으로 가까운 매장을 검색하고 매장별 즉시 사용 가능한 장비 수량을 제공합니다.

- 이용 내역 조회
우선순위: P2
설명: 사용자의 과거 세탁 이용 기록 정보를 조회합니다.

### 4.2. 관리자 기능 (Admin Features)
- 실시간 매장 관제 대시보드
우선순위: P0
설명: 매장 내 모든 세탁기의 가동 현황, 잔여 시간, 오류 상태를 한눈에 파악할 수 있는 웹 대시보드를 제공합니다.

- 장비 점검 모드 전환
우선순위: P0
설명: 고장이나 점검이 필요한 장비를 관리자 페이지에서 '점검 중' 상태로 전환하여 이용자의 사용을 차단합니다.

- 장애 및 오류 즉시 알림
우선순위: P0
설명: AI 비전 OCR을 통해 에러 코드가 감지되거나 모듈 통신이 끊겼을 때 관리자에게 즉시 SMS 또는 Push 알림을 발송합니다.

- OCR 원본 스냅샷 검증
우선순위: P1
설명: OCR 인식 오류가 의심될 경우, 관리자가 카메라가 촬영한 원본 세탁기 디스플레이 이미지를 관제 화면에서 직접 비교·확인합니다.

- 가동률 통계
우선순위: P1
설명: 장비별, 시간대별, 요일별 가동률 데이터 시각화 차트를 제공합니다.

### 4.3. AI 비전 OCR 및 상태 추론 엔진 (AI Vision OCR & State Engine)
- OCR 수신 API (Webhook/REST)
우선순위: P0
설명: 세탁기 정면 카메라 모듈이 5~10초 주기 또는 이미지 변화 감지 시 수집한 JSON 텍스트 데이터를 수신하는 백엔드 API를 구축합니다.

- OCR 데이터 노이즈 필터링
우선순위: P0
설명: 빛 반사나 왜곡으로 일시적으로 잘못 인식된 텍스트 수치(예: 30분 -> 80분 순간 오인식)를 이전 데이터 흐름과 비교하여 정상 수치로 보정 및 스무딩 처리합니다.

- 상태 추론 엔진 (State Machine)
우선순위: P0
설명: OCR 텍스트 변화 패턴에 따라 장비 상태를 자동 업데이트합니다.
세부조건 1: 숫자가 감소하는 패턴일 경우 '사용 중' 및 잔여 시간 업데이트
세부조건 2: 디스플레이 숫자가 소등되거나 0 표시 시 '완료' 및 완료 알림 발송 후 '대기 중'으로 전환
세부조건 3: E, F 등 에러 패턴 문자 인식 시 '장비 오류' 상태로 전환 및 에러 코드 저장

- 실시간 데이터 동기화 (WebSocket / SSE)
우선순위: P0
설명: 상태 추론 엔진에서 결정된 최종 장비 상태 및 잔여 시간을 프론트엔드(웹/앱 UI)로 2초 이내에 실시간 동기화합니다.
